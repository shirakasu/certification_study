# OSI参照モデル

## OSI参照モデルとは？

コンピュータネットワークにおける，通信をする上で守らなければいけない約束，ルールのことをプロトコルという．
様々な情報をやり取りする上では，この決まりがないとお互いに通信が出来なくなってしまう．
通信における各種プロトコルはOSI参照モデルの７階層によって以下のように分類されている．

| 層 | 名称 | 概要 |
| --- | --- | --- |
| **7層** | アプリケーション層 | 具体的にどんなサービスを提供するのか |
| **6層** | プレゼンテーション層 | データをどのように表現するか |
| **5層** | セッション層 | 通信の開始から終了をどのように管理するか |
| **4層** | トランスポート層 | 通信の信頼性をどう確保するか |
| **3層** | ネットワーク層 | ネットワークとネットワークをどう繋げるか |
| **2層** | データリンク層 | 同一ネットワーク内でどう通信するか |
| **1層** | 物理層 | 物理的にどう繋ぐか |

覚える際には上位層から「アプセトネデブ」で覚えると良い．

## プロトコルとOSI参照モデルの対応表

| 名称 | プロトコル |
| --- | --- |
| アプリケーション層 | HTTP, FTP, DNS, SMTP, POPなど |
| プレゼンテーション層 | SMTP, FTP, Telnetなど |
| セッション層 | TLS, NetBIOSなど |
| トランスポート層 | TCP, UDP, NetWare/IPなど |
| ネットワーク層 | IP, ARP, RARP, ICMPなど |
| データリンク層 | PPP, Ethernetなど |
| 物理層 | RS-232, UTP, 無線 |

## セキュアプロトコルとOSI参照モデルの対応表

| 層 | 名称 | 代表的なセキュアプロトコル |
| --- | --- | --- |
| **7層** | アプリケーション層 | SSH |
| **6層** | プレゼンテーション層 | - |
| **5層** | セッション層 | - |
| **4層** | トランスポート層 | TLS |
| **3層** | ネットワーク層 | IPsec |
| **2層** | データリンク層 | L2TP |
| **1層** | 物理層 | - |
