# 契約形式

## 請負契約

依頼者に対して請負者が仕事の完成を約束し，成果物に対して依頼者が報酬を払う契約形態のこと．
つまり，成果物に責任を持つ契約．
労働者は受託企業との雇用契約関係および指揮命令関係があり，委託企業との関係はない．

## 派遣契約

派遣会社から発注先の企業へ労働者を派遣し，発注者の指示のもとで業務を遂行する契約形態のこと．
派遣元との雇用契約関係，および派遣先との指揮命令関係が労働者にはある．

## 出向契約

元の会社との雇用関係および身分を存続させたまま，長期間にわたり出向先企業の管理および指揮命令下で勤務する契約形態のこと．
労働者は出向先企業との雇用契約および指揮命令関係があり，元の企業との雇用契約関係もある．

## 準委任契約

一部の作業を手伝う名目で業務を遂行する契約形態のこと．
つまり，成果物の完成責任は負わず，作業報告書を委任者（自社の責任者）に収める．

## 準委任契約と請負契約のどちらが適切か？

情報システム・モデル取引・契約書<第2版>に照らした場合，以下のようになる．

| 開発工程 | 適切な契約形態 |
| --- | --- |
| **システム化の方向性（企画段階）** | 準委任契約 |
| **システム化計画（企画段階）** | 準委任契約 |
| **要件定義（企画段階）** | 準委任契約 |
| **システム外部設計（開発段階）** | 準委任契約・請負契約 |
| **システム内部設計（開発段階）** | 請負契約 |
| **ソフトウェア設計（開発段階）** | 請負契約 |
| **プログラミング（開発段階）** | 請負契約 |
| **ソフトウェアテスト（開発段階）** | 請負契約 |
| **システム結合（開発段階）** | 請負契約 |
| **システムテスト（開発段階）** | 準委任契約・請負契約 |
| **受入・導入支援（開発段階）** | 準委任契約 |
| **運用テスト（運用段階）** | 準委任契約 |
| **運用（運用段階）** | 準委任契約・請負契約 |
| **保守（保守段階）** | 準委任契約・請負契約 |
