## 電力変換回路

以下の表の用語が過去問で出た．

| 用語                 | 変換内容    | 説明                         |
| -------------        | -------     | ----------------             |
| インバーター         | DC → AC | 直流を交流に変換する             |
| コンバーター（AC/DC）| AC → DC | 交流を直流に変換する             |
| コンバーター（DC/DC）| DC → DC | 直流の電圧を変換する             |
| AC/ACコンバーター    | AC → AC | 交流の電圧や周波数などを変換する |
| 整流器               | AC → DC | 交流を直流方向の電流に変換する   |
